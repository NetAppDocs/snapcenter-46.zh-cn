= 升级工作流
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
每个 SnapCenter 版本都包含一个更新的 SnapCenter 服务器和插件软件包。插件软件包更新随 SnapCenter 安装程序一起分发。您可以将 SnapCenter 配置为检查可用更新。

此工作流显示了升级 SnapCenter 服务器和插件软件包所需的不同任务。

image::../media/upgrade_workflow.png[升级工作流]

[NOTE]
====
* SnapCenter 仅支持沿上表中显示的路径进行直接升级。如果需要升级到当前版本不直接支持的版本，则必须执行一系列增量升级。例如，如果您使用的是 SnapCenter 版本 4.3.x 并希望升级到 4.6.x，则应首先升级到 4.5.x，然后进行滚动升级到 4.6.x。此方法可确保版本之间的兼容性，并防止跳过中间版本时可能发生的问题。在开始升级之前，请始终验证表中支持的升级路径。
* 有关升级 SnapCenter Plug-in for VMware vSphere 的信息，请参见 link:https://docs.netapp.com/us-en/sc-plugin-vmware-vsphere/scpivs44_upgrade.html["升级适用于 VMware vSphere 的 SnapCenter 插件"^]
